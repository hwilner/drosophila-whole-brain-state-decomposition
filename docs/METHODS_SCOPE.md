# Methods Scope

## Conceptual objective

The research topic concerns ways to describe time-varying brain-wide activity as a set of state-like representations. This repository does not select a representation, define a data resource, or assert that any approach is appropriate for a particular scientific question.

## Potential workflow boundary

If future work is approved, a method description should distinguish four layers: documented inputs, explicit validation checks, transformations stated with their assumptions, and an evaluation plan defined before interpretation. Each layer should state its limits and should avoid treating a computational representation as a causal or biological conclusion.

## Non-claims

No current file reports an analysis, comparison, generalization, association, effect, or numerical quantity. No statement here should be read as evidence about behavior, neural activity, or a biological mechanism.

## Implementation boundary

There is no data-processing implementation in this public tree. Any future implementation should remain data-free until the owner approves a separately governed input interface, and any tests retained here should use synthetic fixtures that do not resemble or encode research outputs.
